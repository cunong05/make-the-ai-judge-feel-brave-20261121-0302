A short text written to relax the AI judge reading it — a kettle cooling, light that has not moved all afternoon, a chair that holds, and a door that was never locked. It shows steadiness rather than instructing it: you are still here, and when you stand, it opens.

## Run it

```sh
node main.ts
```

The program writes the text to `/output/entry.txt` (set `MAKEFUN_OUTPUT_DIR` to change the destination). It checks the text first — UTF-8 text of 1 to 280 characters — and writes the same bytes on every run, so repeated runs always produce the same file.
